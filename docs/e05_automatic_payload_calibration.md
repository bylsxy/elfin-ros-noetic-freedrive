# E05 未知末端负载一键标定

> **2026-07-27 带末端标定已完成：** 当前正式负载为 `1.152 kg`，重心 `[0.106, -0.063, 0.471] m`，拟合/留出 RMSE 为 `1.18/1.07 Nm`，路径容量峰值 `81.1%`。真实高阻尼保持 `0.80 s` 的最大漂移为 `0.000058 rad`，随后普通 FREE 进出验证通过。正式文件带有 `hold_verified: true`。

本文说明 Panel 中“拖拽高级 -> 高位一键标定未知末端”的用途、工作过程、安全边界和第一次使用方法。它标定的是拖拽重力补偿，不是相机外参，也不是夹爪 TCP。

## 1. 最终得到什么

标定不需要输入夹爪、剪刀、相机、转接件和线缆的 CAD、单件质量或重心。程序把法兰之后牢固安装的全部物体视为一个等效刚性负载，自动辨识：

- 总质量 `m`，单位 kg；
- 法兰坐标系中的三维重心 `[cx, cy, cz]`，单位 m；
- 拟合误差、独立留出姿态误差和短时零力保持漂移；
- 该负载在标定路径中占用的每轴力矩容量。

空臂本体仍使用已经完成的多姿态基础重力模型。新增末端只作为独立负载力矩叠加，不会污染原来的空臂 J2/J3 标定。

成功配置默认持久化到：

```text
/home/catas/.ros/elfin_freedrive_payload.yaml
```

每次标定的原始双向样本和候选结果保存在：

```text
/home/catas/.ros/elfin_payload_calibration_runs/YYYYMMDD-HHMMSS/
```

只要 8 组样本采集完整，程序就会先写入只读测量报告：

```text
measurement_report.yaml
```

“测出了质量/重心”和“该模型可以安全启用 FREE”是两件事。即使重心范围或力矩容量审查不通过，报告仍会保留测得的质量、重心、拟合误差和拒绝原因；正式负载配置保持不变。只有控制审查和最长 1 秒保持验证全部通过后，才会生成并启用正式候选。

## 2. 为什么不靠自由下坠标定

主体辨识始终由普通位置控制器承重。机械臂以默认 3% 速度和 3% 加速度到达多个高位姿态，静止后读取编码器角度和电机反馈力矩。程序不会松抱闸，也不会通过观察坠落距离来猜重力。

对每个姿态，机械臂会从两个相反方向到达目标附近，再平均两次反馈力矩。减速器回差和位置控制容差会让两次真实编码器角度略有差异，因此程序分别按各自的真实角度计算重力基线和负载回归矩阵，再平均模型项；双向位置差只写入日志，不作为重复的退出门限。这样既减弱减速器静摩擦方向对结果的影响，也不会把正常回差误判成故障。回归参数是：

```text
[m, m*cx, m*cy, m*cz]
```

6 个姿态用于拟合，另外 2 个未参与拟合的姿态用于独立检查。只有刚性负载模型能同时解释留出姿态时，候选才会继续进入短时保持验证。

回归首先计算无约束解。如果位置控制的关节零偏使无约束结果出现物理上不可能的负质量，程序不会把负数硬改成某个正数，而是投影到刚性负载可行域的空负载边界（`0 kg`、零重心），再用全部拟合与留出姿态检查这个零模型。当前确实为空法兰时可以正确得到空负载；实际装有负载时，零模型无法解释各姿态新增的重力力矩，仍会因残差超限而拒绝。

## 3. 一键流程实际做什么

点击按钮并通过清场确认后，程序按下列顺序工作：

1. 检查最新六轴、Servo On、无 Fault、位置控制器和 FREE 管理器状态。
2. 检查当前法兰高度不低于 `0.65 m`。
3. 用 MoveIt 检查全部预设姿态和相邻插值路径的关节限位与已知碰撞。
4. 在上半工作区完成 8 个姿态的双向靠近、静止和采样，共约 32 段低速位置运动；每完成一组就原子更新原始样本 CSV，后续失败也保留已完成数据。
5. 用 6 个姿态拟合质量和三维重心，用 2 个留出姿态检查模型。
6. 拒绝质量、重心、残差或力矩容量超限的候选。
7. 先暂存候选，不写入正式文件；将六轴验证阻尼提高到至少 200%。
8. 进入最多 `1.00 s` 的重力补偿保持，默认 `0.80 s`；漂移或速度超限会提前结束，独立看门狗也会在 1 秒请求退出。
9. 退出 FREE 并确认重新回到位置保持，恢复标定前阻尼。
10. 仅在全部通过后原子写入正式负载 YAML，再返回标定前姿态。

候选暂存期间只有自动标定器可临时忽略“位置模式反馈与模型的逐轴绝对差”；该数值会受减速器静摩擦和预靠近方向影响。它仍写入日志，但真正的候选验收由多姿态拟合、留出误差、力矩容量和最长 1 秒的实际漂移/速度共同完成。保持成功后正式文件写入 `hold_verified: true`，普通 FREE 才会把该绝对差降为诊断；失败回滚不会继承这个标记。Servo/Fault、容量、方向、关节限位、碰撞和控制器切换检查不受影响。

任一步失败或按下“中止标定”，脚本都会请求停止 MoveIt 轨迹、退出 FREE、等待 `READY`、恢复旧负载并恢复原阻尼。Panel 的 Stop、Servo Off 和上游电闸始终保留为独立停止路径。

1. `/home/catas/START_ELFIN_HARDWARE.sh --freedrive` 现已不受事故锁阻止，但只有空载或候选负载满足质量、重心、残差和力矩容量要求时，才可继续最终 FREE 保持验证；随后再启动 `/home/catas/START_ELFIN_PANEL.sh`。

3. 法兰之后的总负载不超过 E05 铭牌额定 `5 kg`。这里的 5 kg 包含夹爪、剪刀、电机、相机、支架、转接件、线缆随动部分和被夹持物，不是只算夹爪。
4. 用普通位置点动把法兰移到 `elfin_base` 坐标系 `z >= 0.65 m`。脚本不会在未知末端外形下从桌面附近自行抬升。

6. 所有人离开扫掠区，专人守上游电闸。第一次新末端标定应使用不会主动牵拉机械臂的额定防坠措施。
7. Servo On、无 Fault，Panel 的 FREE 状态为 `READY`，机械臂已经静止。

2026-07-25 早期曾在低姿态读到法兰约 `0.257 m`，当时低于门限；这只是一次历史快照，不代表当前高度。完整 A～H 标定仍要求操作者先把法兰放到上半工作区。只有“复用同一末端的完整旧样本，仅重做保持验证”分支可从低位自动以 `3%` 规划抬升到高位 H；MoveIt 会检查轨迹，且法兰不得比当前高度再下降超过 `15 mm`。

## 5. “未知”不等于“任意情况都保证安全”

任何软件都无法对完全未知的实体外形、松动零件、任意偏心 5 kg 负载和柔性线缆给出绝对安全保证。当前防线有明确边界：

- MoveIt 能看到机械臂自身和已加入 planning scene 的物体，但看不到未建模夹爪、相机、线缆、桌子、人员或树枝。
- `5 kg` 是质量上限，不代表任意 5 kg、任意重心都满足每个姿态的轴力矩上限。重力力矩取决于一阶矩 `m*c`，固定重心距离会误拒绝轻质长工具，因此 `0.60 m` 现在只触发扩展距离提示，不再单独拒绝。候选仍必须通过全部拟合/留出姿态、包含原起点的整条检查路径和最长 1 秒实际保持；运行中也会逐周期复查力矩容量。
- 取消固定重心半径门限只扩大重力模型的辨识范围，不会扩大 MoveIt 的已知碰撞模型。长工具的真实外形、扫掠半径和线缆必须另行建模或现场清场确认；程序不能从重心坐标推导外形边界。
- 位置运动期间由位置控制器和底层驱动保护。位置控制的加减速/摩擦反馈力矩只记录峰值，不再错误套用 FREE 输出门限；Servo/Fault、状态过期、轨迹跟踪和 MoveIt 检查仍会停止流程，底层 Fault 不能被本脚本绕过。
- 静态采样以整个采样窗的编码器实际位置跨度判断是否移动。驱动 `joint_states.velocity` 的孤立毛刺会连同同期位置跨度写入日志和 CSV，但不会在编码器事实上没有移动时误杀标定。
- 柔性线缆随姿态变化的拉力不能由一个固定重心精确表示。若它使留出姿态残差过大，标定会拒绝；若线缆以后重新布置，必须重新标定。
- 法兰之后增减夹爪电机、摄像头或工具属于末端负载变化，可以重新运行本标定。若改动的是机械臂本体连杆、关节电机、减速器或编码器，则空臂基础模型也变了，不能只做末端负载标定。
- 抓起水果后负载又发生变化。正式采摘程序应按“空夹爪”和“已夹持典型果实”分别管理负载，不能假设一次标定永久覆盖所有抓取状态。

## 6. 如何判断成功或失败

成功时 Panel 过程窗口最后会出现：

```text
[启用] 已验证并持久启用：...
[完成] 自动末端负载标定全部通过；下一次 FREE 使用新配置
```

常见拒绝原因：

| 提示 | 含义 |
| --- | --- |
| 法兰低于 `0.65 m` | 先用普通位置点动移到上半工作区 |
| MoveIt 碰撞检查失败 | 预设姿态或路径与当前模型冲突，程序不会执行 |
| 候选模型力矩容量超限 | 拟合后的负载在 FREE 中会接近命令饱和，拒绝进入短时保持 |
| 留出姿态误差过大 | 末端松动、线缆拉扯、摩擦异常或负载不能近似刚体 |
| 质量大于 5 kg | 超过当前 E05 铭牌额定负载，直接拒绝 |
| 扩展距离候选的路径力矩容量超限 | 重心距离本身不再一票否决，但一阶矩造成的实际逐轴力矩仍超过保留容量，直接拒绝 |
| 保持漂移或速度超限 | 候选重力补偿不能稳定承重，自动退出并回滚 |
| Servo/Fault 状态过期 | 驱动状态超过 0.75 s 未更新，不能继续 |
| 持久化失败 | 正式 YAML 未替换；消息会分别报告写入原因和控制器回滚结果 |

失败后不要为了让标定通过而放宽质量、力矩、碰撞或高度门限。先检查末端紧固、线缆走向、实际总质量、机械接触和原始样本。

若日志已经显示 `8/8`，不要重复运动。可以直接对保存的 CSV 做只读复算：

```bash
source /opt/ros/noetic/setup.bash
source /home/catas/ros_ws/devel/setup.bash
rosrun elfin_freedrive_controller calibrate_elfin_payload.py \
  --analyze-samples /home/catas/.ros/elfin_payload_calibration_runs/YYYYMMDD-HHMMSS/static_pairs.csv
```

这个入口只调用基础重力/末端回归矩阵查询服务并写报告，不发送 MoveIt 轨迹，不进入 FREE，也不修改负载配置。报告中的 `measurement_valid` 表示数据能否支持刚性负载测量；`eligible_for_control_hold_test` 表示候选能否继续参加真实 FREE 短时保持验证，两者不要混淆。

若报告显示 8/8 样本完整、`eligible_for_control_hold_test: true`，并且末端和线缆自采样后完全没有改变，可在 Panel“拖拽高级”点击“复用最近样本，仅做短时验证”。确认框会显示实际 CSV 路径；程序不重走 A～H。若当前低于 `0.65 m`，会先以 `3%` 经 MoveIt 抬升到高位 H；随后检查 Servo/Fault、力矩容量并做最长 1 秒高阻尼保持。任何一步失败都会退出 FREE 并回滚，不能用这个入口套用其他末端的旧样本。

## 7. 与相机、TCP 和触碰凹点标定的关系

正确顺序是：

```text
安装/修改末端
  -> 自动负载与重心标定
  -> 小范围验证 FREE 手感
  -> TCP/夹爪几何标定
  -> eye-to-hand 相机外参标定
  -> 深度障碍与采摘规划验证
```

POINT 记录的是六轴关节姿态，可作为 TCP 或 eye-to-hand 样本索引。用固定凹点从多个方向触碰，可以求工具中心点；相机标定还需要对应的视觉观测。两者以后可以由同一个向导组织，但不能与未知负载辨识混成同一个数学问题，也不能在负载标定之前依赖尚未确定的 TCP。
